# Alan Wake VR

Unofficial Virtual Reality Mod by [fholger](https://github.com/fholger)

## About the project

This mod brings the original Alan Wake to life in your VR headset. The mod features
6dof headset tracking and synced stereo rendering for a smooth and artifact-free VR
experience. Gameplay remains unchanged in this first release - the game is still a 3rd
person experience and best experienced seated with a gamepad (or alternatively keyboard
and mouse). A first person mode with motion controls might come in a later update.

## Supported game versions

This mods supports the original Alan Wake from GOG, Steam or Epic Games. Other game versions are not supported. Alan Wake Remastered is not supported. American Nightmare
might become supported in the future.

## Download the mod

You can find the latest mod version on [the mod page](https://alanwake.vrmods.eu).
Simply run the installer and point it to your game folder. Then run Alan Wake normally,
and it should launch in VR.

## Uninstallation

There should be an uninstaller in your game folder. Alternatively, you can simply
remove or rename the d3d9.dll from the game folder, and the game will return to being
flat.
